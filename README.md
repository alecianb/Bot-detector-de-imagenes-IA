Este proyecto consiste en un bot de Discord desarrollado en Python que utiliza inteligencia artificial para analizar imágenes enviadas por los usuarios. Su objetivo es detectar si una imagen contiene un gato y, si lo detecta, clasificarlo para determinar si es un gato real o una imagen de un gato generada por inteligencia artificial.

<img width="677" height="601" alt="image" src="https://github.com/user-attachments/assets/2a28e96e-613f-49d1-abfe-c061474da541" />


El bot utiliza YOLO para detectar si la imagen contiene un gato: si no detecta ninguno, la rechaza y solicita una imagen de un gato; si detecta uno, utiliza Teachable Machine para clasificarlo como gato real o generado por inteligencia artificial.
